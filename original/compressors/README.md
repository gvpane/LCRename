# Liquid Channel Compressor Emulations

This folder contains all of the compressor replicas (`.lqc` files) for the Liquid Channel. Below is the official mapping from Focusrite detailing what real-world hardware each emulation pseudonym is based on.

### 40 Original Factory Emulations

* **FLAT COMP / CLEAN SOUND FREE CONTROLS**: Focusrite Liquid Channel DSP compressor.
* **TRANY C / US CLASSIC DISCRETE 1C**: Based on an API 2500 stereo mastering compressor (Old/Normal/Hard settings).
* **TRANY A / US CLASSIC DISCRETE 1A**: Based on an API 2500 stereo mastering compressor (Old/Normal/Soft settings).
* **TRANY R / US CLASSIC DISCRETE 1R**: Based on an API 2500 stereo mastering compressor (NEW, Loud and Hard settings).
* **SILVER 2 / US MODERN TUBE 1**: Based on an AVALON VT-737SP valve channel strip.
* **LIVE SOUND / BRIT LIVE SOUND 1**: Based on a BSS DPR402 dual compressor/limiter.
* **LONDON / BRIT BOUTIQUE TUBE 1**: Based on a CHISWICK REACH stereo valve compressor.
* **WASP 2 / BRIT CLASSIC SOLID STATE 1**: Based on a DRAWMER DL221X.
* **WASP 1 / BRIT CLASSIC TUBE 1**: Based on a DRAWMER 1960 vacuum tube compressor amplifier.
* **BIG BLUE A / US MODERN SOLID STATE 1A**: Based on a dbx 160S compressor/limiter (Standard compression setting).
* **BIG BLUE B / US MODERN SOLID STATE 1B**: Based on a dbx 160S compressor/limiter (OverEasy compression setting).
* **US RADIO / US CLASSIC SOLID STATE 1**: Based on a dbx 165 compressor/limiter.
* **COPY CAT / US MODERN COPY CAT**: Based on an EMPIRICAL LABS EL8 DISTRESSOR.
* **COPY CAT 2 / US MODERN COPY CAT 2**: Based on an EMPIRICAL LABS EL8 DISTRESSOR (Distortion 2 setting).
* **COPY CAT 3 / US MODERN COPY CAT 3**: Based on an EMPIRICAL LABS EL8 DISTRESSOR (Distortion 3 setting).
* **VINTAGE / US VINTAGE TUBE 1**: Based on a FAIRCHILD MODEL 670.
* **FF ISA 130 / FOCUSRITE CLASSIC ISA 130**: Based on a FOCUSRITE ISA 130.
* **FF GREEN 5 / FOCUSRITE GREEN CHANNEL STRIP**: Based on a FOCUSRITE CHANNEL STRIP.
* **FF RED 7 / FOCUSRITE CLASSIC RED 7**: Based on a FOCUSRITE RED 7.
* **DUNK A / US MODERN FET 1**: Based on a MANLEY SLAM! (FET limiter).
* **DUNK B / US MODERN OPTICAL 1**: Based on a MANLEY SLAM! (ELOP (opto) limiter).
* **PRIMITIVE / US CLASSIC TUBE 2**: Based on a MANLEY STEREO "VARIABLE MU".
* **BIG GREEN / BRIT CLASSIC OPTICAL**: Based on a JOE MEEK SC2 COMPRESSOR.
* **NEW AGE 2E / US MODERN HYBRID 2E**: Based on a MILLENNIA STT-1 (Solid state input, solid state compressor settings).
* **NEW AGE 2A / US MODERN HYBRID 2A**: Based on a MILLENNIA STT-1 (Vacuum tube input, Vacuum tube compressor settings).
* **NEW AGE 2B / US MODERN HYBRID 2B**: Based on a MILLENNIA STT-1 (Vacuum tube and transformer input, vacuum tube compressor settings).
* **NEW AGE 2F / US MODERN HYBRID 2F**: Based on a MILLENNIA STT-1 (Solid state and transformer input, solid state compressor settings).
* **CLASS A 1 / BRIT 70'S CLASS A 1**: Based on a NEVE 2254/A dual/stereo compressor/limiter.
* **CLASS A 2 / BRIT 70'S CLASS A 2**: Based on a NEVE 33609/B dual/stereo compressor /limiter.
