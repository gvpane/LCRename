# Liquid Channel Preamp Emulations

This folder contains all of the preamp replicas (`.lqm` files) for the Liquid Channel. Below is the official mapping from Focusrite detailing what real-world hardware each emulation pseudonym is based on.

### 40 Original Factory Emulations

* **FLAT e-BAL / CLEAN SOUND 10kø ELECTRONIC**: Liquid Channel transparent transformerless mono mic-pre.
* **FLAT trfmr / CLEAN SOUND 10K ø**: Liquid Channel transparent transformer-based mono mic-pre.
* **THE GUV / BRIT MODERN SOLID STATE 1**: Based on an AMEK Pure Path dual mic-pre.
* **VALVE / US MODERN HYBRID 1**: Based on an APHEX Thermionics Model 1100 discrete Class A tube dual mic-pre.
* **US TRANY / US CLASSIC DISCRETE 1**: Based on an API 3124+ discrete quad mic-pre.
* **TRANY H / US CLASSIC DISCRETE 1 HOT**: Based on an API 3124+ discrete quad mic-pre.
* **SILVER 1A / US MODERN DISCRETE 1 Hø**: Based on an AVALON AD 2022 dual mono Class A pre-amp.
* **SILVER 1B / US MODERN DISCRETE 1 Mø**: Based on an AVALON AD 2022 dual mono Class A pre-amp.
* **SILVER 2 / US MODERN TUBE 1**: Based on an AVALON VT-737SP valve channel strip.
* **BRIT 70'S / BRIT CLASSIC DESK 3**: Based on a CADAC G Series 268E console mic-pre.
