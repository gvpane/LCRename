# Liquid Channel Final Replicas

This folder contains the completely renamed and descriptively padded Liquid Channel replication files (`.lqm` for preamps and `.lqc` for compressors).

The files have been named according to their authentic real-world hardware models. Furthermore, to maximize readability on the hardware screen's 32-character description limit, specific Focusrite modifiers have been expanded using standardized abbreviations.

## Naming Convention Abbreviations

### Amplification & Topology
*   **VT**: Vacuum Tube topology (no transformer)
*   **VT+T**: Vacuum Tube topology with transformer
*   **SS**: Solid State (no transformer)
*   **SS+T**: Solid State with transformer

### Impedance
*   **Hz**: High Impedance
*   **Mz**: Medium Impedance
*   **Lz**: Low Impedance
*   *(Some specific Ohm values like 150 Ohm and 600 Ohm are retained explicitly)*

### Gain & Padding
*   **H** (or **HOT**): Preamp driven hard (High input gain for saturation)
*   **P** (or **PAD**): Padded input setting

### Compressor Specifics
*   **HK**: Hard Knee
*   **SK**: Soft Knee
*   **Dist 2 / Dist 3**: Emulation of the Distressor's Dist 2 and Dist 3 modes
*   **OEZ**: OverEasy (dbx specifically)
*   **CRS**: Crush (Smart Research C2)

## File Organization
*   `preamps/`: `.lqm` files representing microphone preamplifiers.
*   `compressors/`: `.lqc` files representing dynamic range compressors.
